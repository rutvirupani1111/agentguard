# agentguard

Prompt-injection firewall for AI agents: find hidden instructions in web pages, emails and documents before your LLM reads them.

> Work in progress. See `docs/STATUS.md` once it lands.

- Zero dependencies, TypeScript, ESM + CJS
- Deterministic, offline, explainable

## Install

```bash
npm install agentguard
```
